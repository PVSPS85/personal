# Personal Code Practice Repository

This repository contains C and C++ practice programs, structured cleanly by domain and topic.

## Directory Structure

```text
personal/
├── c/
│   ├── basics/              # Foundational C programs (strings, pointers, records, math)
│   ├── data-structures/     # Stacks, queues, linked lists, expression conversion/evaluation
│   ├── algorithms/          # Sorting and searching algorithms
│   └── practice/            # Additional practice exercises and problem sets
├── cpp/
│   ├── basics/              # C++ syntax, pointers, references, structs, classes, enums
│   ├── functions/           # Function overloading, arrays with functions
│   ├── recursion/           # Recursive algorithms (Tower of Hanoi, Ackermann function)
│   └── practice/            # Diverse C++ practice problems
└── .gitignore               # Ignores compiled binaries and temporary build files
```

## Compilation Examples

### C Programs
```bash
gcc c/basics/helloworld.c -o helloworld
./helloworld
```

### C++ Programs
```bash
g++ cpp/basics/hello_world.cpp -o hello_world
./hello_world
```
